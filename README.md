# Learn AI - Introdução à Inteligência Artificial com Python

## 📄 Descrição

Este projeto é um **notebook interativo** (.ipynb) voltado para **estudo e experimentação em Inteligência Artificial (IA)**, utilizando **Python** como linguagem principal.

O objetivo é apresentar conceitos básicos de IA e Machine Learning de forma prática e acessível.

---

## ⚙️ Conteúdo do Notebook

- Introdução ao que é IA e Machine Learning
- Importação de bibliotecas fundamentais (NumPy, Pandas, Matplotlib)
- Criação de modelos de aprendizado supervisionado
- Treinamento e avaliação de modelos
- Visualização de dados e resultados

---

## 🚀 Como Executar

1. Certifique-se de ter o **Python** instalado (versão 3.8 ou superior).

2. Instale o **Jupyter Notebook** e bibliotecas necessárias:
```bash
pip install notebook numpy pandas matplotlib scikit-learn
```

3. Inicie o Jupyter Notebook:
```bash
jupyter notebook
```

4. Abra o arquivo `learn_ai.ipynb` e execute as células passo a passo.

---

## 📊 Tecnologias Utilizadas

- Python 3
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
